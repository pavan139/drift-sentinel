# Changing a detector or alert transition

A new metric is also a new member of the testing family. Update the allocation argument in `analysis/spending-and-delay.md` before adding a channel, and keep reference uncertainty in its boundary. Recovery and cooldown must not reset a channel's look counter.

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
python -m ruff check src tests
python -m ruff format --check src tests
```

For statistical changes, retain independently enumerated null examples as well as the seeded trajectories. For join changes, test labels in both arrival orders, duplicates, conflicts and pending-state capacity. Never infer a missing label's correctness from a prediction or a feature alert.

Keep evaluation seeds separate from any threshold tuning. If a new experiment uses informative missingness, clustered requests or another feature range, describe that sampling change in `analysis/change-trajectories.md` rather than carrying over the old false-opening interpretation. JSON and Prometheus output in `measurements/` should retain the observed denominators and censoring.
